# Bloodchain branding (shared)

Place your **logo** here as **`logo.png`** (PNG with transparency works well). The file previously named `logo.svg` was PNG data; the app now uses **`logo.png`** everywhere for correct browser support.

After updating, copy `logo.png` to each app:

- `azure/public/branding/logo.png`
- `high-command/public/branding/logo.png`
- `mars-lab/public/branding/logo.png`
- `scyther/public/branding/logo.png`
- `voyager/public/branding/logo.png`

Favicons and nav bars reference `/branding/logo.png`.
