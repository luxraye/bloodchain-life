## Conventions

- Public link in all outbound material: **https://www.bloodchain.life** (marketing site only; no module URLs are published).
- Module demos are shared privately during briefings via `https://bc-<module>.onrender.com`.
- Each brief follows one shape: **problem → module → pilot box → requirements → the ask**.
- Style: peer-professional, Botswana-specific, honest about maturity. No hype.

## How to produce sendables

1. Open a `.md` in VS Code / Typora / Google Docs.
2. Apply brand: burgundy `#A81F38` headings, dark navy or white background, logo from `demo-hub/public/branding`.
3. Export to PDF (briefs, DNA) or paste emails into your mail client.
