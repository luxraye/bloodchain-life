# Beachhead pilot one-pagers

Use these once a discovery conversation confirms the assumption (see `assumptions-log.md`). Each pilot is small, time-boxed, and has one number that decides success. Do not broaden scope mid-pilot.

---

## Pilot A (default) — Scyther + Azure @ Blood for Life Botswana

| Field | Detail |
|-------|--------|
| Problem | Donors give once and are never brought back; drives run on paper |
| Scope | One blood drive, end to end, plus one retention cycle |
| Duration | 90 days |
| Primary metric | % of drive-day donors registered on Azure, then contacted for a return slot |
| Secondary metrics | Time per donor at intake; duplicate-registration rate |
| Pricing | P1,500–3,000 / month licence **or** per-drive fee for corporate CSR drives |
| We provide | On-site setup, staff training, drive-day support line |
| They provide | One coordinator, one drive, consent to follow up with donors |
| Kill condition | Donors will not register / cannot be re-contacted -> stop, document, pivot |

## Pilot B — Transfuse @ Gaborone Private Hospital

| Field | Detail |
|-------|--------|
| Problem | No active HTxC record-keeping / haemovigilance (WHO-flagged gap) |
| Scope | Transfusion request + committee record + adverse-event log for one ward/unit |
| Duration | 90 days |
| Primary metric | Adverse events recorded in Transfuse vs prior (paper) baseline |
| Pricing | P3,000–8,000 / month SaaS |
| We provide | Setup, clinician training, weekly check-in |
| They provide | Blood bank lead, one unit to pilot, confirmation IT stack is not group-mandated |
| Kill condition | Group IT policy blocks adoption -> stop, try Bokamoso or another private hospital |

## Pilot C — Chronicle @ Baylor Children's CCE

| Field | Detail |
|-------|--------|
| Problem | Missed scheduled transfusions for paediatric chronic blood disorders |
| Scope | ~50 paediatric patients on a transfusion schedule |
| Duration | 90 days |
| Primary metric | Care-gap alerts surfaced; reduction in missed scheduled transfusions |
| Pricing | Implementation + licence (funder-backed), set after scoping |
| We provide | Setup, clinician training, weekly check-in, ethics-aligned data handling |
| They provide | Clinical coordinator, named clinical champion, ethics guidance |
| Kill condition | Records already in an adequate EMR -> stop, redirect Chronicle elsewhere |
